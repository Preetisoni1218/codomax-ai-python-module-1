## Topics Covered

### 1. Artificial Intelligence (AI)

Artificial Intelligence is a technology that enables computers to perform tasks that normally require human intelligence, such as learning, reasoning, problem-solving, and decision-making.

### 2. Machine Learning (ML)

Machine Learning is a branch of AI in which computers learn patterns from data and use them to make predictions or decisions.

### 3. Deep Learning

Deep Learning is a subset of Machine Learning that uses artificial neural networks with multiple layers to learn complex patterns from large amounts of data.

## AI vs ML vs Deep Learning

| Technology    | Meaning                                    |
| ------------- | ------------------------------------------ |
| AI            | Broad field of making machines intelligent |
| ML            | Machines learn from data                   |
| Deep Learning | Uses multi-layer neural networks           |
